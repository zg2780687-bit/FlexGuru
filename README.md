# 六关节机械臂控制程序

## 1. 项目简介

本项目实现六关节机械臂的基础校准与控制功能。

机械臂由 6 个 FEETECH SCS215 舵机组成，每个舵机对应一个机械臂关节。由于不同关节实际能够安全运动的范围不同，因此需要先对每个关节进行校准，记录其最小和最大安全位置。

完成校准后，用户只需要输入 6 个 `0~1` 范围内的数值，程序就可以根据每个关节的校准范围，将输入值转换为对应的舵机目标位置，并控制六个舵机运动。

---

## 2. 程序文件

### `calibrate.py`

用于校准六个舵机的运动范围。

程序依次对 ID 1~6 的舵机进行校准：

1. 将当前关节移动到最小安全位置。
2. 按下 Enter。
3. 程序通过串口读取舵机当前位置。
4. 将该位置记录为最小位置 `min`。
5. 将当前关节移动到最大安全位置。
6. 按下 Enter。
7. 程序再次读取舵机当前位置。
8. 将该位置记录为最大位置 `max`。

最后将六个舵机的校准结果保存到 `calibration.json`。

---

## 3. `calibration.json`

该文件用于保存校准结果。

示例：

```json
{
    "1": {
        "min": 200,
        "max": 700
    },
    "2": {
        "min": 300,
        "max": 800
    },
    "3": {
        "min": 100,
        "max": 600
    }
}
